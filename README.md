# make_richman_exchange_rate

토스뱅크 외화통장(17개 통화, 환전수수료 0원)용 환율 알림 봇.
GitHub Actions 가 30분마다(Cloudflare Worker 가 매시 10분·40분에 실행을 부름) 환율을 확인해,
1시간에 한 번 **17개 통화 전부를 '최근 180일 중 하위 %' 낮은 순으로 정리한 표**를 텔레그램으로 보낸다.
매수·매도 판단과 기록은 사람이 토스 앱에서 직접 한다 (봇은 보유·손익을 다루지 않는다).

## 동작

1. 17개 통화의 현재 환율과 최근 180일 일별 환율을 가져온다 (하나은행 매매기준율, 실패 시 Yahoo Finance).
2. 통화별로 현재 환율이 기간 내 어디쯤인지(하위 %)와, 과거 같은 구간에서 1·3·5·10·20거래일 뒤 올랐던 비율을 붙인다.
3. 한 통(코드 블록 하나)으로 보낸다. 하위 % 오름차순, 같은 %끼리는 5거래일 확률이 높은 순.
   한국 시각 기준 시간대마다 한 번만 보내고, 환율 조회 실패는 알리지 않는다.
4. 마지막으로 읽은 텔레그램 메시지 번호와 발송 시간대를 `state/state.enc` 로 암호화해 커밋한다.

기간은 `config.toml` 의 `lookback_days` 로 바꾼다.

## 텔레그램 명령

| 명령 | 뜻 |
|---|---|
| `신호` | 정기 알림과 같은 표를 지금 보내달라고 하기 (`/signal`) |
| `환율` | 전체 통화 현재 환율과 180일 중 위치·기간 최저~최고 (`/rates`) |
| `도움말` | 쓸 수 있는 명령 (`/help`) |

거래 기록 명령(`매수`/`매도`/`현황`/`취소`)은 없앴다. 그 밖의 말에는 도움말로 답한다.

명령은 다음 실행(매시 10분·40분)에 처리된다. 바로 반영하려면 Actions 탭에서 `fx-monitor` 를 수동 실행한다.

## 설정

1. 텔레그램에서 @BotFather 로 봇을 만들고 토큰을 받는다. 만든 봇에게 아무 메시지나 보낸다.
2. 로컬에서 키와 chat id 를 확인한다.
   ```
   pip install -r requirements.txt
   python -m fxbot keygen                          # → STATE_KEY
   TELEGRAM_TOKEN=<토큰> python -m fxbot chatid    # → TELEGRAM_CHAT_ID
   ```
3. 저장소 Settings → Secrets and variables → Actions 에 `STATE_KEY`, `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID` 를 등록한다.
   `STATE_KEY` 를 잃어버리면 상태 파일을 새로 만들어야 한다 (`state/state.enc` 삭제).

## 공개 저장소 주의

공개 저장소라 Actions 무료 한도(2,000분)를 쓰지 않는다. 대신 코드와 Actions 로그는 누구나 볼 수 있다.

- 봇은 보유량·거래 내역을 저장하지 않고, 로그에는 환율 조회 성공 개수만 남는다 (명령·알림 건수도 남기지 않음).
- `config.toml` 에는 개인 금액·보유 정보를 적지 않는다.

## 상승 확률 표

알림에 붙는 '오를 확률'은 과거 10년 하나은행 환율로 만든 표(`fxbot/odds.json`)에서 읽는다.
통화별·하위 % 구간별로 1·3·5·10·20거래일 뒤 상승 비율을 세고, 표본이 적은 통화는 전 통화 공통 확률 쪽으로 당겨 쓴다.
알림에는 다섯 구간(1d·3d·5d·10d·20d)을 모두 적고, 같은 하위 %끼리의 정렬은 5거래일 확률 기준이다.
표를 새로 만들려면 `python -m fxbot backtest`.
