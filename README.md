# make_richman_exchange_rate

토스뱅크 외화통장(17개 통화, 환전수수료 0원)용 환율 매매 신호 봇.
GitHub Actions 가 1시간마다 환율을 확인해 **싸면 매수 신호, 수수료를 빼고도 이익이면 매도 신호**를 텔레그램으로 보낸다.
체결은 토스 앱에서 직접 하고, 체결 내용을 텔레그램으로 봇에게 알려주면 기록이 암호화되어 저장소에 보관된다.

## 동작

1. 17개 통화의 현재 환율과 최근 90일 일별 환율을 가져온다 (Yahoo Finance, 시장 중간값 ≈ 토스 매매기준율).
2. 텔레그램으로 받은 매수·매도 기록을 반영한다.
3. 신호 판단
   - 매수: 현재 환율이 90일 중 하위 5% 이하. 이미 보유 중인 외화는 보유분 평균 매수 환율보다 쌀 때만 (횟수 제한 없음).
   - 매도: 수수료를 모두 빼고 산 가격보다 조금이라도 비쌀 때. 손해·본전 매도 신호는 보내지 않는다.
   - 같은 신호는 12시간 안에 다시 보내지 않는다 (환율이 0.5% 더 유리해지면 예외).
4. 기록이 바뀌었으면 `state/state.enc` 로 암호화해 커밋한다.

기준값은 `config.toml` 에서 바꾼다.

## 텔레그램 명령

| 명령 | 뜻 |
|---|---|
| `매수 USD 1350.5 1000` | 1,350.5원에 1,000달러 샀음 (환율은 토스 표시 그대로, 엔·루피아·동은 100 단위) |
| `매도 JPY 905.2 100000` | 100엔당 905.2원에 10만 엔 팔았음 (선입선출로 실현손익 계산) |
| `매도 JPY 전량매도` | 가진 엔화 전부 팔았음 (환율은 봇 처리 시점 시장 환율, `매도 JPY 905.2 전량` 처럼 환율을 적어도 됨) |
| `현황` | 보유 외화, 매도 목표 환율, 평가손익 |
| `환율` | 전체 통화 현재 환율과 90일 중 위치 |
| `기록` / `취소` | 보유 외화별 평균 매수 환율 / 마지막 기록 삭제 |

명령은 다음 정시 실행(매시 정각, GitHub 사정으로 늦어질 수 있음)에 처리된다. 바로 반영하려면 Actions 탭에서 `fx-monitor` 를 수동 실행한다.

## 설정

1. 텔레그램에서 @BotFather 로 봇을 만들고 토큰을 받는다. 만든 봇에게 아무 메시지나 보낸다.
2. 로컬에서 키와 chat id 를 확인한다.
   ```
   pip install -r requirements.txt
   python -m fxbot keygen                          # → STATE_KEY
   TELEGRAM_TOKEN=<토큰> python -m fxbot chatid    # → TELEGRAM_CHAT_ID
   ```
3. 저장소 Settings → Secrets and variables → Actions 에 `STATE_KEY`, `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID` 를 등록한다.
   `STATE_KEY` 를 잃어버리면 기록을 복구할 수 없으니 따로 보관한다.

## 공개 저장소 주의

공개 저장소라 Actions 무료 한도(2,000분)를 쓰지 않는다. 대신 코드와 Actions 로그는 누구나 볼 수 있다.

- 거래 기록·보유량은 암호화 파일에만 있고, 로그에는 환율 조회 성공 개수만 남는다 (명령·알림 건수도 남기지 않음).
- `config.toml` 에는 개인 금액·보유 정보를 적지 않는다.
